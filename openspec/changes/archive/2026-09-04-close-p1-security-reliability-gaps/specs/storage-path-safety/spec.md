## Purpose

为所有由 config、env、text、同步条目或索引派生的本地路径建立统一且跨平台的存储边界，防止路径穿越、目录逃逸、符号链接跳转和越界删除。

## ADDED Requirements

### Requirement: 存储标识必须是安全单路径段

凡用于构造受管存储路径的 name、group 或 key，系统 SHALL 要求其非空、不是 `.` 或 `..`、不含 NUL、`:`、`/`、`\\` 或平台卷标/绝对路径语义。该规则 MUST 在管理层和实际文件存储边界同时执行。

#### Scenario: 非法标识矩阵被拒绝
- **WHEN** 任一入口提供空值、`.`、`..`、`../x`、`a/../../x`、`a\\b`、绝对路径、含 NUL 或卷标形式的存储标识
- **THEN** 系统返回明确的非法标识错误，且不读取、创建、覆盖或删除任何文件

#### Scenario: 合法单段标识被接受
- **WHEN** name、group 或 key 是不含保留字符的单一路径段
- **THEN** 系统仅在该标识所属的预期存储根目录内执行操作

### Requirement: 所有派生路径必须保持在可信根内

系统 SHALL 在执行读取、写入、替换、rename 或删除前验证规范化后的目标位于其预期可信根目录内。仅做字符串前缀检查 MUST NOT 视为有效 containment 验证。

#### Scenario: 规范化后逃逸
- **WHEN** 外部数据或历史索引解析出的候选路径在规范化后位于可信根之外
- **THEN** 操作 fail closed，目标和同步状态均保持不变

#### Scenario: 不同存储根相互隔离
- **WHEN** config、env、text、metadata 或 config index 执行文件操作
- **THEN** 每种对象只能访问其规范定义的 data 或 config 子树，不得借标识进入其他根

### Requirement: 路径操作拒绝符号链接跳转

受管文件的创建、覆盖、替换和删除 SHALL 拒绝目标或从可信根到目标之间任一父组件为符号链接。若平台无法提供无竞态的等价保证，系统 MUST fail closed。

#### Scenario: 目标是符号链接
- **WHEN** 受管目标已被替换为指向根外文件的符号链接
- **THEN** 写入或删除被拒绝，链接目标内容保持不变

#### Scenario: 父目录是符号链接
- **WHEN** 目标任一父目录是指向其他位置的符号链接
- **THEN** 操作被拒绝，系统不沿链接访问或修改任何对象

### Requirement: 递归删除受边界保护

任何递归删除 group 或受管目录的操作 MUST 在验证安全标识、containment 和无符号链接后执行；验证失败时 MUST 删除零个对象。

#### Scenario: 非法 group 删除请求
- **WHEN** 删除 group 的标识为 `..`、绝对路径或含路径分隔符
- **THEN** 系统拒绝请求，可信根及其外部目录均保持不变

#### Scenario: 被污染索引参与删除
- **WHEN** 索引中的文件名与规范身份不一致或指向可信根外
- **THEN** 系统报告索引损坏，不删除候选路径
