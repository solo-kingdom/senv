# mcp-server-tui 增量

## ADDED Requirements

### Requirement: 多选批量导出与撤回

MCP tab 左栏档案列表 SHALL 支持多选集（`space` 勾选、`a` 全选可见集，语义见 tui-viewer「多选集与批量操作」）。`x`/`u` 在多选集非空时范围为「选择集 × 右栏当前 agent」，`X`/`U` 范围为「选择集 × 全部导出目标 agent」；计划页语义（动作标注、漂移与外部条目默认 skip、`F` 覆盖、确认写入、取消不写盘、被改条目逐条确认）与单档案完全一致，仅范围扩大。多选集为空时保持既有「当前档案」语义。

#### Scenario: 勾选两档案导出全部 agent
- **WHEN** 用户勾选 2 个档案后按 `X` 并确认计划
- **THEN** 计划覆盖 2 × 全部导出目标 agent 的条目，确认后逐个写入（单个失败不中止其余）

#### Scenario: 漂移覆盖作用到选择集
- **WHEN** 选择集中某档案在某 agent 上标为 drift，用户按 `F` 后确认
- **THEN** 该条目被覆盖，其余语义不变

#### Scenario: 取消不写盘
- **WHEN** 用户在批量导出计划页按 `esc`
- **THEN** 任何 agent 配置与台账均不变，选择集保留（未提交）

#### Scenario: 空集回落当前档案
- **WHEN** 用户未勾选任何档案按 `x`
- **THEN** 范围为当前选中档案 × 当前 agent，行为与既有要求一致
