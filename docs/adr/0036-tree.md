# 路径树（Tree）：加密多级文件树存储与增量同步

`deploy/`（容器编排、Caddy/CoreDNS 配置、部署计划）与 `wireguard/`（脱敏配置模板、节点清单、运维脚本）天然是**多层级目录树**，日常工作流依赖按路径单文件读写、多文件 unified diff、增量拉推与可执行位保留。senv 现有的 `env`/`text`/`backup`/`ledger` 为两层扁平寻址（组名禁含 `/`），`config` 仅支持单文件映射，`skill` 虽支持 tar 目录树但要求根下含 `SKILL.md` 且整包重传。本 ADR 决定在 senv 中新增通用路径树能力 `senv tree`。

## 决策

1. **新增两个同步 kind：`tree`（单文件密文）与 `tree_meta`（分组说明）。**
   - `grp` 为单个安全路径段（`securefs.ValidateSegment`），表示树根命名空间（如 `deploy`、`wireguard`）。
   - `key` 为 POSIX 相对路径（如 `tcbj/caddy/configs/Caddyfile`），`tree_meta` 要求 `grp` 非空、`key` 为空。
   - **一文件一条目，不引入共享可变索引**：避免多机并发修改同目录不同文件时发生索引冲突；列表靠递归扫描，单文件直接复用 `senv history` 与 `senv sync` 乐观锁/tombstone。

2. **路径安全与碰撞防护**
   - `syncschema.ValidateRelativePath(path)` 按 `/` 切段后逐段调用 `securefs.ValidateSegment`；禁止前导/尾随 `/`、空段（`//`）、`.`、`..`、`\`、`\x00`、`:`，深度 ≤ 16 层、总长 ≤ 512 字节。
   - **路径前缀碰撞检查**：同一 `grp` 下禁止同时存在文件 `a/b` 与目录前缀 `a/b/...`；写入或拉取前 fail-closed 校验。

3. **本地存储与载荷格式**
   - 密文落盘：`trees/<grp>/<seg1>/.../<filename>.enc`；组说明复用 `trees/<grp>/.meta.enc`。
   - 载荷（加密 JSON）：`schema`（1）、`mode`（`0o600`/`0o644`/`0o755`，保留 `+x` 可执行位）、`encoding`（`utf8`/`base64`）、`content`、`sha256`（明文摘要，用于快速 diff）、`description`、`updated_at`。
   - 单条体积复用 `senv-server` 默认 **512 KiB** 密文上限（明文上限 **384 KiB**），天然拦截 `.dump` / 视频等大二进制误入库。
   - 不做 `{{env:...}}` 自动解引用，保持编排模板原文的字节忠实性。

4. **CLI 访问面（`senv tree`）**
   - 单文件：`ls [grp[:prefix]]`、`get <grp>:<path>`、`set <grp>:<path> [--file|--exec|--description]`、`edit <grp>:<path>`（仅 TTY，解密到 0600 临时文件开 `$EDITOR` 后写回并清理）、`rm <grp>:<path> [--yes]`。
   - 目录增量：`diff <grp>[:prefix] <local-dir>`、`pull <grp>[:prefix] <dest-dir> [--dry-run] [--yes] [--delete]`、`push <local-dir> <grp>[:prefix] [--dry-run] [--yes] [--delete]`。
   - 分组管理：`group list | add <name> --description "..." | delete <name>`。
   - `push` 默认忽略 `.git/`、`.env`、`*.dump`、`*.sql.gz`、`*.bak*`、`*.key`、`*.pem`（可通过 `--include-ignored` 覆盖）。

5. **MCP 访问面（3 个工具）**
   - `senv_tree_ls`（只读列目录/文件元数据）、`senv_tree_get`（只读读单文件内容）、`senv_tree_set`（单文件写，拒绝 `.env`/`*.key`/`*.pem` 等敏感路径并写 `op_mcp_tool` 审计）。不暴露 `rm` / `pull` / `push`。

6. **横切集成**
   - 接入 `server_state` 同步收集与 `entryLocation` 映射、`consistency`/`rekey`/`rekey_manifest`/`doctor`/`history`/`search`（索引 `grp`、`relpath` 与 `description`，不索引正文）及 `AuditOpTree` 审计。

## 发布顺序

- `senv-server` 升级（`syncschema` 白名单合入）→ 全员 `senv` 客户端滚动升级 → `senv tree push` 迁移 `deploy/` 与 `wireguard/`。
