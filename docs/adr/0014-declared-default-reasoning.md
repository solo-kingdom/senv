# 默认推理档是声明值，不按模型推断

增改 Provider 模型集时，凡声明了推理档位的模型必须能解析出默认推理档：显式 per-model、集合级声明、或模型目录（目录目前没有该字段）。senv 不从档位列表形状或模型 id 猜测「该用 high」。无档位的模型不要求该项；旧档案缺字段仍可切换，Codex 投影用 `none` 占位且不回写。理由是模型迭代快，写进 senv 的特例会过期；动态事实只来自配置与外部目录。

## Considered Options

- **启发式**（有 `high` 用 `high` / 取末档 / 取首档）：少一次输入，但把会过期的模型知识写进 senv。
- **与 context window 完全同门**：无档位的模型也要填默认推理档，目录 add 在 models.dev 补字段之前会全部失败。
- **切换时静默回写旧档案**：旧 vault 被猜值污染，违反「旧档案可不补全并继续读取」。

## Consequences

- 集合级 `--default-reasoning` 只填充「有档位且尚未解析出默认推理档」的模型，不盖到无档位模型上。
- 解析出的默认推理档必须属于该模型的档位列表，否则拒绝写入。
- models.dev 若日后提供 default effort，装配路径可直接吸入，不必改政策。
- 旧档案切 Codex 时可能落到 Think-Off，直到用户 `edit` 补上声明。
